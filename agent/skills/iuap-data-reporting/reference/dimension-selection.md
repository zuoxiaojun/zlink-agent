# 动态分析维度选择

> 本规则定义报告技能如何根据数据特征自动选择分析维度。

---

## 维度触发规则

| 数据特征 | 触发的分析维度 |
| ---------- | ---------------- |
| 时间字段 + 数值指标 | 趋势分析 |
| 分类字段 + 数值指标 | 结构分析 |
| 多个分类维度 | 归因分析 |
| 可对比的分组 | 对比分析 |
| 数值分布范围大 | 异常检测 |
| 率/比值指标 | 效率分析 |
| 多指标同时存在 | 相关性分析 |

---

## 执行要求

- 至少完成 3 个分析维度
- 每个维度输出：维度标题 + 核心发现 + 数据支撑

---

## 维度与图表映射

| 分析维度 | 可视化技能自动选择 |
| ---------- | ------------------- |
| 趋势分析 | line / area / bar |
| 结构分析 | pie / donut / treemap |
| 归因分析 | bar / waterfall |
| 对比分析 | bar |
| 异常检测 | scatter / boxplot |
| 效率分析 | bar / gauge |
| 相关性分析 | scatter / bubble |
