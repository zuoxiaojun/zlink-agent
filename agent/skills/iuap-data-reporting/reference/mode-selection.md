# 意图识别与模式选择

> 本规则定义报告技能如何识别用户意图并选择执行模式。

---

## 模式识别规则

```
用户消息包含以下任一信号 → 用户驱动模式：
  - 明确的分析框架/结构/章节
  - 具体的分析步骤或顺序
  - 自定义的分析思路/方法论

用户消息未包含上述信号 → 自主模式（默认）
```

---

## 模式对比

| 维度 | 自主模式 | 用户驱动模式 |
| ------ | ---------- | -------------- |
| 分析规划 | MECE假设树→探索框架 | 按用户指定框架执行 |
| 查数策略 | 自主判断数据缺口 | 按用户规划取数 |
| 输出结构 | 7阶段流水线结构 | 按用户指定章节 |

---

## 自主模式流程

详细方法论 → [insight-framework.md](../reference/methodology/insight-framework.md)

| 阶段 | 目标 | 产出 |
| ------ | ------ | ------ |
| 0. 数据理解 | 建立全局认知 | 数据概况、质量评分卡 |
| 1. 假设重构 | MECE 拆解问题 | 假设树、优先级排序 |
| 2. 系统探索 | 六维框架探索 | 趋势/分布/对比/异常发现 |
| 3. 统计验证 | 验证显著性 | 检验结论、置信区间 |
| 4. 洞察综合 | 提炼洞察 | 洞察列表、置信度评级 |
| 5. 预测分析 | 向前看一步 | 趋势预测、情景分析 |
| 6. 迭代取数 | 补充缺口 | 完整分析证据链 |

---

## 用户驱动模式流程

1. 解析用户指定的分析框架/章节结构
2. 按用户规划顺序执行分析
3. 按用户指定结构组装报告
