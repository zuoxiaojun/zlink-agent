# 统计方法与验证

本文档定义了分析过程中使用的统计方法和验证规则。

---

## 描述统计

**必须计算的统计量**：

```
集中趋势：
- 均值、中位数、众数

离散程度：
- 标准差、变异系数(CV)、四分位距(IQR)

分布形态：
- 偏度(skewness)、峰度(kurtosis)

百分位数：
- P5、P25、P75、P95
```

---

## 显著性检验

| 检验场景 | 方法 | 判断标准 |
| --------- | ------ | --------- |
| 两个群体差异 | t 检验 / Welch t 检验 | p < 0.05 |
| 多个群体差异 | 方差分析(ANOVA) | p < 0.05 |
| 比例差异 | 卡方检验 / Z 检验 | p < 0.05 |
| 趋势是否存在 | 线性回归斜率的 t 检验 | p < 0.05 且 R² 有意义 |
| 相关性 | Pearson/Spearman | \|r\| > 0.3 弱，> 0.5 中，> 0.7 强 |

---

## 置信区间计算

```
均值置信区间：x̄ ± t × (s / √n)   # 95% 置信水平
比例置信区间：p̂ ± z × √(p̂(1-p̂)/n)   # 95% 置信水平
```

## 效果量评估

| 指标 | 公式 | 判断标准 |
| ------ | ------ | --------- |
| **Cohen's d** | (μ₁ - μ₂) / σ_pooled | 0.2 小、0.5 中、0.8 大 |
| **提升率** | (实验组 - 对照组) / 对照组 | 结合业务场景判断 |
| **贡献度** | 部分变化量 / 总变化量 | 排名各因素贡献大小 |

---

## 异常值检测方法

| 方法 | 适用场景 | 判断标准 |
| ------ | --------- | --------- |
| **Z-score 法** | 近似正态分布 | \|Z\| > 2 轻微异常，\|Z\| > 3 严重异常 |
| **IQR 法** | 任意分布 | 超出 Q1-1.5×IQR 或 Q3+1.5×IQR |
| **时间序列异常** | 有时间维度 | 偏离移动均值超过 2 个标准差 |
| **业务规则异常** | 有明确阈值 | 如退货率 > 30%、利润率为负等 |
| **突变点检测** | 寻找拐点 | 相邻期变化率超过历史均值 + 2σ |

## 数据质量评估

### 评估维度

| 维度 | 检查内容 | 健康标准 |
| ------ | --------- | --------- |
| **完整性** | 各字段缺失率 | ✅ < 5%  ⚠️ 5-20%  ❌ > 20% |
| **准确性** | 异常值/不合理值检测 | 业务规则校验 |
| **一致性** | 时间格式、数值单位、分类标准 | 口径统一 |
| **时效性** | 最新数据点距今天数 | 是否存在时间断层 |
| **唯一性** | 主键重复、完全重复行数 | 无重复 |

### 数据清洗处理

| 问题类型 | 处理方法 | 注意事项 |
| --------- | --------- | --------- |
| 缺失值 | 数值型用中位数填充；分类型用众数或"未知"填充 | 记录填充方式 |
| 异常值 | 标记但不直接删除；单独分析异常值群体规律 | 异常值可能是关键洞察来源 |
| 格式不统一 | 标准化日期格式、数值精度、分类名称 | 保持原始数据可追溯 |
| 重复数据 | 去重，记录去重数量 | 先确认是否为业务上的合理重复 |

## 趋势预测方法

| 方法 | 适用条件 | 说明 |
| ------ | --------- | ------ |
| **线性外推** | 趋势稳定、无季节性 | 最小二乘法拟合，预测下一周期 |
| **移动平均** | 波动较大、需平滑 | 3期/5期移动平均预测下一期 |
| **同比延伸** | 有明显季节性 | 去年同期 × 增长率预测 |
| **分部件预测** | 可拆解的总量 | 先预测各部件，再加总 |

**预测原则**：

- 始终给出预测区间（如"预计 Q4 营收 850-920万"）
- 明确标注前提假设
- 预测不超过历史数据的 1/4 时间跨度

---

## 情景分析框架

```
基准情景（概率 60%）：基于当前趋势延续
乐观情景（概率 20%）：假设利好因素出现
悲观情景（概率 20%）：假设不利因素出现
```

每种情景给出：预期结果 + 触发条件 + 应对策略

---

## 敏感性分析

- 逐一调整各因素 ±10%/±20%，观察目标指标变化幅度
- 聚焦 Top 3 敏感因素给出建议
