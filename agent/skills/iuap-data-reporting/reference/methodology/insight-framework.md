# 洞察分析方法论

本文档定义了洞察分析的核心方法论框架。

---

## 四层推断模型

每一条分析都应沿推断阶梯向上攀登：

| 层级 | 问题 | 示例 |
| ------ | ------ | ------ |
| **L1 描述性** | 发生了什么？ | "Q3营收同比下降12%" |
| **L2 诊断性** | 为什么发生？ | "主因是大客户流失导致A产品线收入下降28%" |
| **L3 预测性** | 接下来会怎样？ | "按当前趋势，Q4营收将继续下滑5-8%" |
| **L4 规范性** | 应该怎么做？ | "建议立即启动大客户挽回计划，优先锁定前5大客户" |

---

## What / Why / So What 三问驱动

1. **What** — 描述数据中的事实：趋势、异常、分布、对比
2. **Why** — 推断背后的原因：结构性因素、偶发事件、相关性
3. **So What** — 给出可行动的建议：优先关注项、风险预警、机会点

**绝不只停在"这个数字上升了X%"层面。** 每一个观察都要追问：这说明了什么？这重要吗？下一步呢？

---

## 洞察质量标准

- **具体**：不说"增长较快"，说"Q3 增长 34%，是全年最高单季"
- **有意义**：每条洞察都指向一个决策或行动
- **有层次**：区分核心洞察（必须关注）和次要发现（供参考）
- **诚实**：明确数据限制，不过度推断
- **要量化**：尽量用数字表达程度，避免模糊词
- **标置信度**：核心洞察必须标注置信度等级
- **给区间**：预测和估计用区间而非点值

## 洞察分类与标注

| 类型 | 标记 | 适用场景 |
| ------ | ------ | --------- |
| **风险预警** | 🔴 `.risk` | 需要立即关注的负面信号 |
| **机会点** | 🟢 `.opportunity` | 可以利用的正面信号 |
| **结构性发现** | 🟡 `.finding` | 揭示业务底层逻辑的规律 |
| **背景信息** | ⚪ `.info` | 理解数据的必要上下文 |

---

## 置信度评估体系

| 置信度 | 标记 | 条件 | 含义 |
| -------- | ------ | ------ | ------ |
| **高** | 🟢🟢🟢 | 统计显著 + 效果量大 + 数据完整 + 多源交叉验证 | 结论可靠，可直接决策 |
| **中** | 🟡🟡 | 有数据支撑但缺少统计验证，或样本量偏小 | 结论可信但需进一步验证 |
| **低** | 🟠 | 仅有相关性或间接证据 | 结论为推测，需谨慎使用 |
| **假设** | ⚪ | 基于逻辑推理但无直接数据支撑 | 仅作为假设方向 |

**判断流程**：满足 3-4 项条件 → 高；2 项 → 中；1 项 → 低；0 项 → 假设

## MECE 假设树构建方法

对核心问题进行 MECE（相互独立、完全穷尽）拆解：

```
核心问题：为什么营收下降？
├── 量的问题（客户数 × 购买频次）
│   ├── 新客户减少 → 假设1：获客渠道效率下降
│   ├── 老客户流失 → 假设2：产品体验/竞品替代
│   └── 购买频次降低 → 假设3：消费力下降/需求转移
├── 价的问题（客单价 × 折扣率）
│   ├── 客单价下降 → 假设4：产品结构下移
│   └── 折扣率上升 → 假设5：促销依赖加深
└── 结构问题（产品/渠道/区域组合变化）
    ├── 高毛利产品占比下降 → 假设6：产品结构恶化
    └── 低效渠道占比上升 → 假设7：渠道结构失衡
```

**MECE 检查规则**：

- 同一层级的假设之间不能有重叠
- 所有假设合在一起必须覆盖问题的全部可能原因
- 每个假设都要可被数据验证或证伪

---

## 假设优先级排序

根据**影响力 × 可验证性**对假设排序：

| 优先级 | 条件 | 处理 |
| -------- | ------ | ------ |
| **P0 优先验证** | 影响大 + 数据可验证 | 立即取数验证 |
| **P1 次要验证** | 影响大 + 数据不足 | 补充取数后验证 |
| **P2 备选** | 影响小 | 有余力时验证 |

## 洞察文字撰写规范

遵循 **"发现→解读→意义"三段式**：

```html
<div class="insight-text">
  <!-- 发现：陈述数据事实 -->
  2025年Q1总营收达 <span class="yonbi-rep-highlight">1,234万元</span>，
  同比增长 <span class="yonbi-vis-trend--up">23.5%</span>。

  <!-- 解读：解释为什么 -->
  <span class="insight-tag opportunity">机会点</span>
  增长主要受3月份大促拉动，新品类贡献了增量的42%，
  成本占比下降 <span class="yonbi-vis-trend--down">5个百分点</span>。

  <!-- 意义：指向行动 -->
  建议加大该品类推广预算，Q2复制大促运营策略。
</div>
```

### 趋势数字样式

在洞察文字中，涉及趋势变化的数字必须使用对应的样式：

| 趋势方向 | 样式类名 | 颜色 | 触发词示例 |
|----------|----------|------|------------|
| 上涨/增长/提升/增加 | `<span class="yonbi-vis-trend--up">` | 橙红 #fb6832 | 增长23.5%、提升10个百分点、同比+15% |
| 下跌/下降/减少/降低 | `<span class="yonbi-vis-trend--down">` | 翠绿 #1cd46b | 下降12%、减少5万、环比-8% |

**判断规则**：

1. 识别数字前的动词/形容词：增长、上升、提高 → yonbi-vis-trend--up；下降、减少、降低 → yonbi-vis-trend--down
2. 识别数字符号：+、↑ → yonbi-vis-trend--up；-、↓ → yonbi-vis-trend--down
3. 仅包裹表示变化幅度的数字，不包裹绝对值数字（绝对值用 `yonbi-rep-highlight`）
