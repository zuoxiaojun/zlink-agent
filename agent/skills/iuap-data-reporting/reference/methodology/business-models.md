# 商业分析模型

本文档收录常用的商业分析模型及其适用场景。

---

## 模型索引

| 模型 | 适用场景 | 分析维度 |
| ------ | --------- | --------- |
| **AARRR 漏斗** | 用户增长分析 | 获客→激活→留存→变现→推荐 |
| **RFM 模型** | 用户分层 | 最近购买时间(R)、频率(F)、金额(M) |
| **杜邦分析** | 利润/ROI拆解 | 将ROE/ROI层层拆解为可操作的子指标 |
| **帕累托(80/20)** | 集中度分析 | Top 20% 客户/产品/渠道贡献多少 |
| **同比环比矩阵** | 综合表现评估 | 横轴同比、纵轴环比，四象限定位 |
| **波士顿矩阵** | 产品/业务组合 | 市场增长率 × 相对市场份额 |
| **同期群分析** | 用户生命周期 | 按时间分组追踪留存/转化/价值变化 |

---

## AARRR 漏斗模型

适用于用户增长分析，从获客到推荐的完整链路：

```
获客(Acquisition) → 用户如何找到我们？
    ↓
激活(Activation) → 用户是否体验到核心价值？
    ↓
留存(Retention) → 用户会回来吗？
    ↓
变现(Revenue) → 用户愿意付费吗？
    ↓
推荐(Referral) → 用户会推荐给他人吗？
```

**关键指标**：

- 获客：渠道流量、CAC（获客成本）、新用户数
- 激活：注册转化率、首次核心行为完成率
- 留存：次日/7日/30日留存率
- 变现：ARPU、付费转化率、LTV
- 推荐：NPS、邀请转化率、病毒系数

## RFM 用户分层模型

基于三个维度对用户进行价值分层：

| 维度 | 含义 | 指标 |
| ------ | ------ | ------ |
| **R (Recency)** | 最近一次购买时间 | 距今天数 |
| **F (Frequency)** | 购买频率 | 一定期间内购买次数 |
| **M (Monetary)** | 购买金额 | 一定期间内消费总额 |

**分层策略**：

| RFM 组合 | 用户类型 | 运营策略 |
| --------- | --------- | --------- |
| 高R高F高M | 重要价值客户 | VIP服务、优先体验 |
| 低R高F高M | 重要保持客户 | 激活召回、专属优惠 |
| 高R低F高M | 重要发展客户 | 提升频次、会员权益 |
| 低R低F低M | 流失客户 | 流失原因分析、低成本触达 |

## 杜邦分析

将 ROE（净资产收益率）层层拆解：

```
ROE = 净利润率 × 资产周转率 × 权益乘数
    = (净利润/销售收入) × (销售收入/总资产) × (总资产/股东权益)
```

**分析逻辑**：

- ROE 下降 → 是利润率问题？周转效率问题？还是杠杆问题？
- 每一层都能继续拆解到具体业务指标

## 帕累托分析（80/20法则）

识别关键少数的贡献度：

**典型应用**：

- Top 20% 客户贡献 80% 收入
- Top 20% 产品贡献 80% 利润
- Top 20% 问题造成 80% 损失

**分析方法**：

1. 按指标降序排列
2. 计算累计占比
3. 识别 80% 边界
4. 聚焦头部优化或尾部改进

## 同比环比矩阵

综合评估各维度的表现变化：

```
         同比增长
            ↑
    ②明星型  |  ①增长型
    (高同低环)| (双高)
  ───────────┼───────────→ 环比增长
    ③衰退型  |  ④潜力型
    (双低)   | (低同高环)
            ↓
```

**四象限解读**：

- ①增长型：势头强劲，持续投入
- ②明星型：稳定增长，保持优势
- ③衰退型：问题严重，需要诊断
- ④潜力型：短期波动，关注趋势

## 波士顿矩阵

用于产品组合分析：

```
         市场增长率
            ↑
    明星     |  问题
(高增长高份额)| (高增长低份额)
  ───────────┼───────────→ 相对市场份额
    现金牛   |  瘦狗
(低增长高份额)| (低增长低份额)
            ↓
```

**策略建议**：

- 明星：加大投资，扩大优势
- 现金牛：收割利润，维持份额
- 问题：选择性投资或放弃
- 瘦狗：逐步退出或转型

---

## 同期群分析

追踪不同时期进入的用户群体的生命周期表现：

**分析维度**：

- 按用户首次购买月份分组
- 追踪每个群体的后续留存、转化、价值变化
- 识别同期差异和长期趋势

**典型发现**：

- 新用户群体质量是否在变化？
- 某次改版后新用户表现是否提升？
- 老用户群体的价值衰减曲线

## 问题分类框架

| 问题类型 | 核心关注 | 典型提问 | 分析重点 |
| --------- | --------- | --------- | --------- |
| **诊断型** | 找原因 | "为什么下降了？" | 因果分析、归因分解 |
| **评估型** | 判好坏 | "表现怎么样？" | 对标基准、差距量化 |
| **发现型** | 找规律 | "有什么趋势？" | 趋势识别、异常检测 |
| **决策型** | 做选择 | "应该投入哪个？" | 多方案对比、ROI分析 |
| **预测型** | 看未来 | "接下来会怎样？" | 趋势外推、情景分析 |
