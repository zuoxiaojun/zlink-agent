# iuap-data-reporting

**给我数据，我给你一份图文并茂的分析报告。**

---

## 快速判断：该不该用我？

| 场景 | 决策 |
| ------ | ------ |
| 生成经营分析报告 / 数据分析报告 | ✅ 用我 |
| 需要深度洞察、多维度分析、全面分析 | ✅ 用我 |
| 生成周报、月报、季报、专项报告 | ✅ 用我 |
| 需要归因分析、趋势预测 | ✅ 用我 |
| 只需要一张图表 / 指标卡 | ❌ 用 iuap-data-visualizing |
| 只需要快速了解数据要点 | ❌ 用 iuap-data-summarizing |
| 需要问答式分析建议 | ❌ 用 iuap-data-analyzing |
| 需要先查询数据 | ❌ 先调用 iuap-data-querying |

---

## 我能做什么

### 核心能力

| 能力 | 说明 |
| ------ | ------ |
| **自主分析引擎** | MECE 假设树 → 7 阶段流水线 → 深度洞察 |
| **多维度分析** | 趋势、结构、归因、异常、预测等维度自动触发 |
| **图文混排报告** | 每章节包含分析文字 + 数据图表，结论有据 |
| **批量委托优化** | 一次性获取所有图表配置，性能提升 80%+ |
| **流式输出** | 渐进式渲染，章节即时呈现 |

### 支持的报告类型

| 报告类型 | 适用场景 | 推荐章节 |
| --------- | --------- | --------- |
| 经营分析报告 | 营收/利润/成本分析，周报月报季报 | KPI总览 → 趋势分析 → 结构拆解 → 异常诊断 → 行动建议 |
| 专题分析报告 | 特定问题深入分析 | 问题定义 → 数据探索 → 原因分析 → 结论与建议 |
| 数据概览报告 | 快速了解数据全貌 | 核心指标 → 分布概况 → 排名 → 关键发现 |
| 对比分析报告 | 多维度/多时期/多群体对比 | 对比维度选择 → 差异量化 → 原因分析 → 改进建议 |
| 漏斗分析报告 | 转化流程各环节分析 | 全景漏斗 → 环节拆解 → 流失定位 → 优化建议 |

## 如何使用

### 触发方式

- **用户直接请求**："生成经营分析报告"、"帮我分析这份数据"、"做个周报"、"深度洞察"
- **关键词**：报告、分析、洞察、多维度、全面、周报、月报

### 典型用法

**用法1：自主模式（推荐）**

```
用户：帮我分析这份销售数据，生成一份经营分析报告
→ 自动规划分析路径 → 执行7阶段洞察分析 → 输出图文报告
```

**用法2：指定报告类型**

```
用户：生成一份销售数据的周报
→ 按周报结构组织 → KPI总览 + 趋势分析 + 异常诊断 + 行动建议
```

**用法3：用户驱动模式**

```
用户：按"趋势→结构→归因"三个维度分析销售数据
→ 按用户指定框架执行 → 输出报告
```

### 技能依赖

| 技能名称 | 依赖类型 | 说明 |
| --------- | --------- | ------ |
| **iuap-data-visualizing** | **强制依赖** | 所有图表、指标卡生成全权委托 |
| iuap-data-querying | 可选依赖 | 无数据时调用查询 |
| iuap-data-file-io | 可选依赖 | 文件读取 |

> ⚠️ **独立部署时必须同时安装 `iuap-data-visualizing` 技能**

### 技能对比

| 维度 | summarizing | analyzing | reporting（本技能） | visualizing |
| ------ | ------------ | ----------- | --------------------- | ------------- |
| 定位 | 轻量摘要 | 问答分析 | 深度报告 | 纯图表 |
| 内容 | 指标卡+摘要 | 回答+图表+建议 | 图文报告 | 图表/指标卡 |
| 篇幅 | 1页 | 灵活 | 多页 | 单图/多图 |
| 分析深度 | 快速总结 | 诊断建议 | 深度洞察 | 无分析 |
| 触发词 | "摘要"、"要点" | "分析一下"、"为什么" | "报告"、"洞察" | "画图"、"图表" |

## 硬约束

| 规则 | 说明 |
| ------ | ------ |
| 单产物输出 | 默认输出 HTML 代码块；用户明确要求"文件"时输出文件 |
| 数据真实 | 所有分析结论必须基于真实数据，绝不杜撰 |
| 图文混排 | 报告必须同时包含文字分析段落和数据图表 |
| 图表委托 | 所有图表全权委托 iuap-data-visualizing，不指定图表类型 |
| 主题统一 | 使用可视化技能的主题 CDN 和 11 艾系列，禁止自定义 |

### 委托协议要点

报告技能向可视化技能委托图表时：

- **只传递"分析目的"**，不指定图表类型
- 图表类型由可视化技能根据数据特征智能选择
- 使用 requests 数组批量委托

| 分析目的 | 可视化技能自动选择 |
| ---------- | ------------------- |
| 趋势分析 | line / area / bar |
| 分类对比 | bar |
| 占比构成 | pie / donut / treemap |
| 相关性分析 | scatter / bubble |
| 分布分析 | histogram / boxplot |
| 排名分析 | 水平 bar |
| 漏斗分析 | funnel / waterfall |
| 多维评估 | radar |

详细委托规则 → [config/delegation.md](config/delegation.md)
