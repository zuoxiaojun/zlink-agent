# 调研分析（Research & Analysis）

## 概述
面向专业的市场调研用户，提供行业洞察、竞品对标、需求验证等专业调研全链路支持。帮助用户从海量信息中提取关键洞察，生成专业的调研报告。

## 核心能力

### 1. 行业洞察
- **行业趋势分析**：分析行业发展方向、技术变革、政策影响
- **市场规模评估**：估算市场容量、增长率、渗透率
- **产业链分析**：梳理上下游关系、关键环节、价值分布

### 2. 竞品对标
- **竞品识别**：识别主要竞争对手及其市场定位
- **产品对比**：功能、定价、渠道、用户体验等多维度对比
- **竞争策略分析**：SWOT 分析、波特五力模型、差异化分析

### 3. 需求验证
- **用户画像构建**：目标用户特征、行为、痛点分析
- **需求优先级评估**：Kano 模型、MoSCoW 方法
- **可行性分析**：技术可行性、商业可行性、市场可行性

### 4. 调研设计
- **调研方案设计**：明确调研目标、方法、样本、时间计划
- **问卷设计**：问题设计原则、量表选择、逻辑跳转
- **样本规划**：样本量计算、抽样方法、配额管理

### 5. 报告生成
- **数据分析**：定量数据分析、定性数据编码
- **洞察提炼**：关键发现、结论建议
- **报告撰写**：结构化报告、可视化呈现、执行建议

## 使用方式

用户可直接提出调研需求，例如：
- "帮我分析一下新能源汽车行业的竞争格局"
- "我想了解智慧医疗市场的规模和趋势"
- "对比分析一下竞品A和竞品B的产品策略"
- "帮我做一份用户需求调研方案"
- "分析当前市场环境下SaaS行业的机遇与挑战"

AI 会根据用户需求，结合 web_search 等工具获取最新信息，生成专业的调研分析内容。

## 输出规范
- 调研报告应当结构清晰、数据支撑充分
- 结论和建议应当具体可执行
- 涉及数据时标注来源和时间
