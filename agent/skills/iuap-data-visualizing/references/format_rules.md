# 数值格式化规则

适用技能：iuap-data-visualizing、iuap-data-reporting、iuap-data-summarizing

## 格式化规则速查

| 数据类型 | 格式化规则 | 示例 |
| --------- | ----------- | ------ |
| 金额 | ≥1万显示"X.XX万"，≥1亿显示"X.XX亿" | ¥63.70万、¥9,850 |
| 数量 | 千分位分隔 | 23,725、1,234,567 |
| 百分比 | 保留1-2位小数，去除末尾0 | 23.68%、5.2% |
| 比率 | 保留2位小数 | 12.34% |
| 整数 | 千分位分隔（可选） | 1,000 或 1000 |
| 小数 | 保留1-2位小数 | 3.14、0.52 |

## 金额格式化规则

```
数值 < 10000        → "¥{数值}"（千分位）
10000 ≤ 数值 < 1亿  → "¥{数值/10000}万"
数值 ≥ 1亿          → "¥{数值/100000000}亿"
```

| 原始值 | 格式化结果 |
| -------- | ----------- |
| 9850 | ¥9,850 |
| 637000 | ¥63.70万 |
| 1234567 | ¥123.46万 |
| 150000000 | ¥1.50亿 |

## 同比/环比格式化

| 原始值 | 格式化结果 | 样式 |
| -------- | ----------- | ------ |
| +23.68% | 同比 +23.68% | yonbi-vis-trend--up（#fb6832） |
| -10.5% | 环比 -10.5% | yonbi-vis-trend--down（#1cd46b） |
| +0% | 同比 0% | yonbi-vis-trend--neutral（#8c8c8c） |

| 趋势方向 | 类名 | 颜色 | 图标 |
| --------- | ------ | ------ | ------ |
| 上涨 | yonbi-vis-trend--up | #fb6832 | fa-arrow-up |
| 下跌 | yonbi-vis-trend--down | #1cd46b | fa-arrow-down |
| 持平 | yonbi-vis-trend--neutral | #8c8c8c | fa-minus |

## 特殊值处理

| 场景 | 处理方式 |
| ------ | --------- |
| 空值/null | 显示 "--" 或 "暂无数据" |
| 0 | 显示 "0" 或 "¥0" |
| 负数 | 保留负号，如 "-¥1,000" 或 "-5.2%" |
| 极大值 | 使用"亿"单位，如 "¥1.50亿" |
