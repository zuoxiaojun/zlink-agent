# iuap-data-visualizing

**给我数据，还你图表。**

---

## 快速判断：该不该用我？

| 场景 | 决策 |
| ------ | ------ |
| 画一张图表 / 生成可视化 | ✅ 用我 |
| 生成指标卡 / KPI 卡片 | ✅ 用我 |
| 已有数据需要可视化展示 | ✅ 用我 |
| 其他技能需要图表产物 | ✅ 用我 |
| 需要分析报告 + 文字解读 | ❌ 用 iuap-data-reporting |
| 需要先查询数据 | ❌ 先调用 iuap-data-querying |
| 需要数据深度洞察 | ❌ 用 iuap-data-analyzing |
| 需要简洁数据摘要 | ❌ 用 iuap-data-summarizing |

---

## 我能做什么

### 核心能力

| 能力 | 说明 |
| ------ | ------ |
| **20+ 图表类型** | 柱状图、折线图、饼图、散点图、雷达图、桑基图、词云、仪表盘、漏斗图、旭日图、矩形树图、韦恩图、鱼骨图、小提琴图、思维导图等 |
| **智能选型** | 根据数据特征自动推荐最合适的图表类型 |
| **指标卡** | 带图标的 KPI 卡片，支持趋势箭头、同环比展示 |
| **信息图** | 信息图可视化，如组织架构图、流程图 |
| **多图布局** | 自适应网格布局（1图居中、2列、2×2网格等） |
| **流式输出** | 支持流式返回图表，便于其他技能嵌入 |

### 图表类型速查

| 数据场景 | 推荐图表 |
| --------- | --------- |
| 趋势变化 | line（折线图）、area（面积图）、candlestick（K线图） |
| 分类对比 | bar（柱状图）、pictorialBar（象形柱图） |
| 占比构成 | pie（饼图，≤5类）、donut（环图，5-7类）、treemap（矩形树图，>7类）、sunburst（旭日图，多层级） |
| 相关关系 | scatter（散点图）、bubble（气泡图） |
| 流向关系 | sankey（桑基图）、chord（和弦图）、graph（关系图） |
| 多维评估 | radar（雷达图）、parallel（平行坐标图） |
| 统计分布 | boxplot（箱线图）、violin（小提琴图）、histogram（直方图） |
| 进度展示 | gauge（仪表盘）、liquidFill（水球图） |
| 漏斗转化 | funnel（漏斗图）、waterfall（瀑布图） |
| 集合关系 | venn（韦恩图） |
| 因果分析 | fishbone（鱼骨图） |
| 文本词频 | wordCloud（词云） |
| 层级结构 | tree（树图）、treemap（矩形树图）、sunburst（旭日图） |
| 思维结构 | mindmap（思维导图） |
| 地理空间 | map（地图）、geo（地理坐标图） |

## 如何使用

### 触发方式

- **用户直接请求**："画个柱状图"、"生成图表"、"可视化这些数据"、"帮我画图"
- **其他技能委托**：iuap-data-reporting 等技能需要图表产物时委托生成

### 典型用法

**用法1：指定图表类型**

```
用户：用柱状图展示各区域销售额
```

**用法2：智能选型**

```
用户：可视化这组销售趋势数据
→ 自动识别为时间序列，推荐折线图
```

**用法3：生成指标卡**

```
用户：生成一个指标卡，销售额 1234 万，环比增长 12%
→ 输出带图标和趋势箭头的指标卡
```

**用法4：多图布局**

```
用户：把这4张图放一起展示
→ 自动 2×2 网格布局
```

| 技能名称 | 说明 |

## 硬约束

| 规则 | 说明 |
| ------ | ------ |
| 输出约束 | 始终输出一个 HTML 产物（默认代码块，用户要求时输出文件） |
| 不做分析 | 不生成报告、不生成分析文字、不生成长文 |
| 数据真实 | 所有图表数据必须来自用户明确提供的内容，无数据不画图 |
| 模板驱动 | 必须调用模板函数生成配置，禁止直接编写完整 option |
| 系列色约束 | 颜色必须从 11 色系列中选择 |
