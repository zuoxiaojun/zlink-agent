## 使用规则

### 默认取色规则（模板自动执行，LLM 无需传色）

LLM 不传 `seriesColor` 时，模板函数不设 `itemStyle.color`，ECharts 主题色板自动接管：

- 第 1 个系列 → `#3293fb`（主体色，defaultTheme 首色）
- 多系列时按 `seriesColors` 数组顺序自动补位
- 饼图/环图按 data index 自动着色

**仅当需要语义化用色**（金额=蓝、利润=绿、成本=金）时，LLM 才主动传 `seriesColor`。

### 传色一致性规则（强制）

调用 `generate*Series` 函数时，`seriesColor` 参数遵循以下规则：

| 传色方式 | 行为 | 是否允许 |
| --------- | ------ | --------- |
| **全不传** | 所有系列都不传 → 主题色板按 index 自动取色，图例与柱线天然一致 | ✅ 推荐 |
| **全套传** | 所有系列都传 → 图例与柱线用 LLM 传的色，天然一致 | ✅ 允许 |
| **半传** | 部分传部分不传 → 图例走主题色板、柱线走 LLM 手写色，**必然脱钩** | ❌ 禁止 |

**关键约束**：

- `generate*Series` 函数已保证 line 系列的 `lineStyle.color` 与 `itemStyle.color` 同步，LLM 无需手动设置 `itemStyle`
- 禁止手写 `itemStyle.color` 但不同步 `lineStyle.color`（会导致图例色与系列色脱钩）。三种合规方式：
  - bare series（只声明 type，不设 itemStyle.color）→ 主题色板自动接管，图例与系列天然一致
  - `generate*Series` 函数生成 → 函数内部同步 lineStyle 与 itemStyle
  - L3 手写完整 series → 必须手动同步 lineStyle.color 与 itemStyle.color

### 多指标图表

**建议**：精简系列数（≤ 5 个），避免视觉过载。超出时由模板按 `seriesColors` 自动补位。

**示例**：销售金额、销售数量、利润率 → 3 个系列，含主体色（语义化取色见 `indicator_mapping.md`）

### 单指标多类别图表

**规则**：类别数决定颜色数（≤11 时从 11 色选取）

**示例**：饼图显示各区域占比 → 不同区域用不同颜色

### 颜色映射规则

| 区分对象 | 使用方式 |
|---------|---------|
| 类别区分 | 使用色相区分（不同颜色） |
| 数值大小 | 使用饱和度/明度区分（同色深浅） |
