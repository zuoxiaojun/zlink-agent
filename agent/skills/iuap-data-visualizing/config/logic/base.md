# 逻辑基础配置（必读）

> 本文件包含数值格式化规则，所有图表必须加载。

## 一、数值格式化规则

### 金额格式化

| 阈值 | 单位 | 除数 | 小数位 |
| ------ | ------ | ------ | -------- |
| ≥ 1亿 | 亿 | 100000000 | 2 |
| ≥ 1万 | 万 | 10000 | 2 |
| < 1万 | - | 1 | 2（千分位） |

### 其他格式化

| 类型 | 单位 | 小数位 | 千分位 |
| ------ | ------ | -------- | -------- |
| 数量 | - | 0 | 是 |
| 百分比 | % | 2 | 否 |
| 比率 | % | 2 | 否 |
| 整数 | - | 0 | 是 |
| 小数 | - | 2 | 否 |

## 二、统一格式化函数

Y轴、tooltip、label 三处必须使用同一格式化函数，确保单位一致。

```javascript
// forAxis: true 时用于 Y轴（1位小数），false 时用于 tooltip/label（2位小数）
function formatUnified(value, forAxis) {
  if (value == null || typeof value !== 'number' || isNaN(value)) return '--';
  
  var decimals = forAxis ? 1 : 2;
  
  if (value >= 100000000) {
    return (value / 100000000).toFixed(decimals) + '亿';
  } else if (value >= 10000) {
    return (value / 10000).toFixed(decimals) + '万';
  }
  return forAxis ? value.toLocaleString() : value.toFixed(2);
}
```

---

## 三、禁止重复追加单位

`formatUnified` 函数已包含单位（万/亿），**禁止在调用后再追加单位**。

| 写法 | 结果 | 判定 |
|------|------|------|
| `formatUnified(v, false) + '万'` | `155.87万万` | ❌ 错误 |
| `formatUnified(v, false)` | `155.87万` | ✅ 正确 |

**如需显示指标名称，在格式化结果前追加**：

```javascript
// ✅ 正确：指标名 + 格式化值
return '实际收入: ' + formatUnified(v, false);
```

## 四、文字中数值引用规范

> 以上格式化规则同样适用于 LLM 撰写的分析文字，不仅限于图表 JS 代码。

1. **原样引用**：文字中数值必须与数据源一致，禁止模糊表述（"约""近""大概"）
2. **单位换算**（与金额格式化阈值一致）：
   - ≥ 1亿 → 用"亿"，保留2位小数
   - ≥ 1万 → 用"万"，保留2位小数
   - < 1万 → 保持原值
   - ⚠️ 不确定时，保持原始数值 + 原始单位，不做换算
3. **换算反验**：换算后必须反向验证，确认与原始值一致
4. **单位统一**：同一段文字中，同类指标必须使用统一单位
