# 销售订单分析异常数据排查日志
> 来源：YS API 2026-04-30 查询，1152条原始记录

## 发现过程

查4月销售数据，用 `isSum=True + date_from=2026-04-01 date_to=2026-04-30` 拉回 1152 条。
初步汇总发现总金额高达 **317,101,430 万（31.7万亿）**，明显异常。

按日期拆分看，**4/18~4/21 占 1028 条**，且金额量级与其他日期差 4~6 个数量级：
- 4/28 订单：¥11 / ¥100,000,000（正常）
- 4/19 订单：¥300,000,000（程澄客户，疑似 payMoney=3亿 或 payMoney=300,000,000 元=3亿元）

## 异常判断方法

先用 Python 按日期分组统计，发现：
```
2026-04-19: 422单, 金额 310,918,484 万（3109亿）
2026-04-21: 46单,  金额 3,544,520 万（35亿）
```

**正确做法**：用 IQR 异常检测或直接用 `sorted` 看最大金额排序，锁定异常日期区间。

## 排除后可用数据

排除 4/18~4/21 后，剩余 124 单，正常金额量级：
```
总金额: 99,976 万（10.0亿）
HHI: 0.7356（极度集中）
```

## 关键教训

1. **YS API 有时会返回单位不一致的 payMoney**（部分订单是元，部分是万元），导致同日期内出现量级差异
2. **数据清洗前置**：分析前先 `sorted` 看最大/最小金额，IQR 异常检测，能快速发现异常日期
3. **HHI 正常值**：4月 HHI=0.74 说明程澄客户占比 94.6%，业务高度集中——这是真实业务特征，不是数据错误
4. **isSum=True vs isSum=False**：isSum=True 时 payMoney 是订单级汇总，isSum=False 时明细行有 oriSum，两者字段名不同不能混用

## 排查命令

```python
# 快速发现异常日期
from collections import defaultdict

daily = defaultdict(float)
for r in records:
    daily[str(r.get("vouchdate", ""))[:10]] += float(r.get("payMoney") or 0)
for k in sorted(daily, key=lambda x: -daily[x]):
    print(f"{k}: {daily[k] / 10000:.1f}万")
```
