# YS API 数据异常记录

## 4/18~4/21 payMoney 金额级异常（2026-04-30）

### 现象
- `isSum=True` 查询 2026-04 全月，返回 1152 条
- 4/18~4/21 共 1028 条，payMoney 金额异常高（百万元~亿元级别）
- 4/22~4/30 共 124 条，payMoney 金额正常（万元级别）
- 正常日期单独统计：124单 / 99,976万元（≈10亿）
- 4/19 程澄客户订单 payMoney=300,000,000（3亿元），其他订单在万元级

### 判断方法
```python
abnormal = {'2026-04-18','2026-04-19','2026-04-20','2026-04-21'}
normal = [r for r in records if str(r.get('vouchdate',''))[:10] not in abnormal]
```
如果 `sum(payMoney)` 超过 100亿 且集中在某几天，基本可判定为异常。

### 根因（待查）
疑似 API 返回值单位折算问题——某些日期字段值未除以 10000。

### 影响
排除异常日后，HHI、客户分布、状态分布均可正常计算。
