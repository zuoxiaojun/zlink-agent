## 十大领域模块（完整内容）

### 1. 智能财税
- **模块标题**：业务驱动实现实时财务管控
- **功能词**：业财一体化 / 事项法会计 / 智能财务 / 合规税务
- **描述**：用友YonSuite 财务运用"事项会计"解耦业务系统与财务系统之间的关系，提供全新的业财融合模式，满足实时、精细、多维的核算与报告需求，助力企业实时管控、赋能业务、控制风险；同时提供以销项管理、进项管理、纳税申报为核心的增值税服务，为企业提供经营过程中所有涉税环节场景服务。

### 2. 数字人力
- **模块标题**：激活人才与激发组织效能
- **功能词**：多维组织管理 / 时间轴 / 人才发现
- **描述**：YonSuite为企业提供包含核心人力，假勤管理，薪资核算，目标绩效，社保管理，薪资预算，编制管理，招聘管理，培训管理九大场景服务。

### 3. 敏捷供应链
- **模块标题**：产业链协同打造敏捷供应链
- **功能词**：全局动态库存管理 / 内部交易平台 / WMS / 采销协同
- **描述**：YonSuite将上游与下游企业涉及的供应商、生产商、分销商等企业间的商流、物流、信息流、资金流融合一体，实现敏捷供应、高效协同。

### 4. 数字营销
- **模块标题**：全渠道营销提升获客与签单能力
- **功能词**：CRM / 电商一体化 / 会员服务 / 多级渠道管理
- **描述**：YonSuite助力企业布局全渠道线上线下一体化的数字化营销体系，提供企业营销、交易、管理、会员、订货、服务的一站式云服务。

### 5. 智慧采购
- **模块标题**：全球采购实现降本增效
- **功能词**：全球寻源 / 社会化交易 / 云采超市 / 供应商管理
- **描述**：YonSuite基于需求方构建的社会化网络交易平台，打通社会化交易与企业供应链、制造流程，连接供应商、2B电商，帮助企业获取全球资源，让采购交易更简单。

### 6. 智能制造
- **模块标题**：推动生产制造向服务经营转型
- **功能词**：LRP / 委外管理 / 设备后服务
- **描述**：YonSuite帮助多制造模式、多工厂的制造企业管控安全、提高质量、缩短交期、提升效率、降低成本，由此提升综合竞争力。

### 7. 智能研发
- **模块标题**：数智驱动研发创新
- **功能词**：产品数据管理 / 研发过程管理 / 协调集成管理 / 研发创新平台
- **描述**：YonSuite支持统一数据架构与产品全生命周期管理，全栈云化，可与 CAD、CAE 等工具无缝集成，实现数据双向交互，提升效率与质量。适配国产环境，融入 IPD 理念，有完善的数据安全保障机制，支持全球研发协同。

### 8. 数字项目
- **模块标题**：全过程管理做好每一个项目
- **功能词**：项目过程管理 / 项目分角色看板 / 项目利润管理 / 项目工时管理
- **描述**：YonSuite支持项目全生命周期管理，为企业提供一体化解决方案，为企业解决打通从商机销售到回款端一体化流程，管控关键业务流程，降低成本，提高项目利润。

### 9. 数智资产
- **模块标题**：助力企业实现资产全生命周期管理
- **功能词**：资产管理台账 / 资产全生命周期跟踪
- **描述**：YonSuite构建全新的数智化的资产管理解决方案，充分发挥在数智化时代下资产数据的业务应用价值，提升企业资产管理水平，提高企业资产的投资回报率。

### 10. 智慧协同
- **模块标题**：业务协作让管理更高效
- **功能词**：多场景企业门户 / 多类型办公应用 / 社会化组织协作 / 移动化协同工作
- **描述**：YonSuite为企业提供协同办公与数智化管理服务，实现企业内外连接，助力企业激发组织活力、提升组织效能、推动组织创新。
