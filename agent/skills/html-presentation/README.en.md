# HTML Presentation (Yonyou-Style HTML Slides)

This is a specification and skill guide for creating HTML presentations with a Yonyou (YonSuite) style PPT aesthetic.

## Project Overview

This project provides a comprehensive set of HTML presentation design specifications, covering design philosophy, color systems, typography rules, layout guidelines, and more, helping developers quickly create presentations that align with Yonyou’s brand identity.

## Design Philosophy

The project adheres to official YonSuite design principles, primarily utilizing a white-background scheme to deliver professional, enterprise-grade presentation solutions.

## Core Design Specifications

### Color System
- **Primary Brand Colors**: Red, White, Gray
- **Color Ratio**: Balanced three-color composition
- **Gradient Rules**: Visual element standards (e.g., arrow gradients)
- **Chart Color Palette**: Unified color scheme for all charts

### Typography Rules
- Font size hierarchy system
- Line spacing guidelines
- Prohibited font usage rules

### Layout Guidelines
- Grid system and margins
- Alignment rules
- White space principles
- Image usage standards

### Slide Types
1. **Hero Slide** – Cover/Title Slide
2. **Pain/Solution** – Two-column comparison of pain points and solutions
3. **Feature Cards** – Capability grid layout
4. **Architecture** – System architecture diagram
5. **Scenarios** – Use case visualization
6. **YonSuite Capability Overview** – White-card style layout
7. **End Slide** – Closing/Thank You Slide

### Decorative Elements
- Three-color short line segments (title accents)
- Geometric decorative slices (top-left corner)
- Grid-textured background (bottom)
- Dot sequence in top-right corner (page number/step indicator)
- Brand logo in top-left corner
- SVG icons

### Optional Enhancements
- Canvas particle animation background
- Floating glow effects

## Logo Guidelines
- Logo embedding standards (minimize external dependencies)
- Base64 embedding standards
- Common troubleshooting: PNG signature verification, IDAT decompression validation

## Use Cases

Ideal for creating:
- Enterprise product presentations
- Technical architecture demonstrations
- Solution overviews
- Product feature showcases
- Training slide decks

## Technology Stack
- HTML5
- CSS3
- SVG (vector icons)
- Canvas (optional animation effects)

Develop according to the design specifications listed in SKILL.md to ensure consistency and professionalism across all presentations.
