# 用友 HTML 风格规范

## 配色

主色：红 #E60012 / 白 #FFFFFF / 灰 #717071

扩展色：深灰 #4A4A4A / 中灰 #717071 / 浅灰 #86868B / 活力橙 #FF6B00 / 科技蓝 #0071E3

背景：白 #FFFFFF / 极浅灰 #F5F5F7 / 网格灰 #FAFAFA

红色用于强调，占比不超过 20%。仅在箭头上使用红白渐变。

## 字体

统一字体：微软雅黑。禁止斜体、下划线、艺术体。

大标题 24-28px 加粗红色，副标题 18-22px 加粗深灰，正文 ≤14px 常规深灰，注释 10-12px 浅灰。

## 布局

白底 + 品牌三色 + 几何点缀 + 底部品牌位。

右下角固定品牌 Logo + Slogan，标题下方三色短线段装饰，所有元素大圆角 border-radius 12-20px，页面留白占比 ≥ 30%。

## 元素

图标统一扁平/伪3D 线性风格，背景可加淡灰网格/点阵纹理，悬浮卡片背景变蓝 + 上浮 + 顶部光条。

## Logo

统一 base64 嵌入 HTML，不依赖外部文件。首页、尾页、中间页左上角均需显示。
